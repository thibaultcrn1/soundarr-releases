# Soundarr — téléchargements

Mélangeur de volume par application pour macOS, dans la barre de menus.

**[⬇︎ Télécharger la dernière version (.dmg)](https://github.com/thibaultcrn1/soundarr-releases/releases/latest/download/Soundarr.dmg)**

1. Ouvrez `Soundarr.dmg` et glissez **Soundarr** dans **Applications**.
2. Au premier lancement : clic droit sur Soundarr › **Ouvrir** (l'app n'est pas encore notariée par Apple).
3. Les versions suivantes s'installent toutes seules.

Toutes les versions et leurs nouveautés : [Releases](https://github.com/thibaultcrn1/soundarr-releases/releases).

---

Ce dépôt ne contient que les versions publiées. Elles y arrivent automatiquement depuis la CI du projet :
chaque archive est signée (Ed25519), et l'app refuse toute mise à jour dont la signature est invalide.
